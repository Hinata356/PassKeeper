# PassKeeper

## 概要

PassKeeper は、「ついついスマホを使ってしまうが、親に預けたりするのは気が引ける」という人に向けて作成しているプロジェクトである。

スマートフォンにはスクリーンタイム機能が存在するが、解除コードを自分で設定する以上、自分で解除できてしまうという問題がある。本プロジェクトは、その解除に必要なパスワードを“意図的に忘れる”ことを目的としている。

PassKeeper はパスワードを自動生成する機能を持ち、さらにそれを一定時間見えないようにする機能を備えている。最初の入力時には一度パスワードを見ることになるが、人間の忘れやすさを前提として設計している。

なお、一瞬で完全に記憶できるほど記憶力が優れている人については想定していない。

将来的には、忘却を促進するためのミニゲームの実装も検討している。

本プロジェクトはローカル環境でのみ動作する。  
また、Google Chrome を想定しており、PCでの動作のみ確認している。
