# PassKeeper

## 概要

PassKeeper は、「ついついスマホを使ってしまうが、親に預けたりするのは気が引ける」という人に向けて作成しているプロジェクトである。

スマートフォンにはスクリーンタイム機能が存在するが、解除コードを自分で設定する以上、自分で解除できてしまうという問題がある。本プロジェクトは、その解除に必要なパスワードを“意図的に忘れる”ことを目的としている。

PassKeeper はパスワードを自動生成する機能を持ち、さらにそれを一定時間見えないようにする機能を備えている。最初の入力時には一度パスワードを見ることになるが、人間の忘れやすさを前提として設計している。

なお、一瞬で完全に記憶できるほど記憶力が優れている人については想定していない。

忘却を促進するためのミニゲーム（ソロ神経衰弱 / 数字暗記）も同梱している。

本プロジェクトは **ローカル環境でのみ動作** する。
**サーバーやバックエンドはなく**、ブラウザ上で完結する。
また、Google Chrome を想定しており、PCでの動作のみ確認している。

---

## 特徴

- パスワードの手動入力 / 自動生成
  - 数字のみ / 英字のみ / 英数字、記号を含める、桁数指定 など
- 期限を設定して、一定時間パスワードを見えない状態にする
- 「緊急表示（回数制限）」で必要なときだけ表示
- 作成済みパスワードの管理（コピー、期限延長、削除、ゴミ箱から復元 など）
- ミニゲーム
  - **ソロ神経衰弱**：数字ペアを全部そろえる（ターン数が少ないほど良い）
  - **数字暗記**：表示された数字を覚えて入力（連続成功回数がスコア）

## 使い方

1. `index.html` をブラウザで開く（サーバー不要）
2. 「新規パスワードを作成」から登録
3. 「ミニゲームで忘れる」から `minigame.html` を開いて遊ぶ

## データの保存について

- 登録したパスワード等のデータは、ブラウザの **localStorage** に保存される。
- そのため、端末やブラウザを変えるとデータは引き継がれない。
- ブラウザの閲覧データ削除（サイトデータ削除）などでデータが消える点に注意。
